## DNS

In GoDaddy DNS for voltedlife.com, add:

- Type: **CNAME**
- Host: **apps**
- Value: **kkwhqpq6gx-afk.github.io**
- TTL: 1 hour (or the default)

Do not change other records. HTTPS on this subdomain starts after that CNAME is in place.
